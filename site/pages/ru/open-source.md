# Открытый код

Код LUME, его спецификация и документы открыты: любой может их прочитать и
сверить друг с другом.

## Где код

Всё лежит в открытом доступе на
[github.com/lumeincc/lume](https://github.com/lumeincc/lume):
криптографическое ядро, [спецификация](/en/spec/crypto/),
[документы](/legal/) и этот сайт. Ретранслятор и приложения для Android и
Windows будут разрабатываться там же.

## На чём построен LUME

| Компонент | Для чего | Лицензия |
|---|---|---|
| [libsodium](https://libsodium.org) | X25519, Ed25519, XChaCha20-Poly1305, SHA-2, HMAC, HKDF, Argon2id, случайные числа | ISC |
| [liboqs](https://openquantumsafe.org) | ML-KEM-768 | MIT |
| Английский словарь BIP39 | слова фразы восстановления | MIT |

Для тестов используются ещё GoogleTest, RapidCheck и nlohmann/json, а также
тестовые векторы Project Wycheproof (Apache 2.0) и Trezor (MIT). Лицензия
каждого файла указана в репозитории в формате [REUSE](https://reuse.software).

## Проверьте сами

- Одна команда настраивает сборку, собирает проект, запускает все тесты и
  пишет отчёт: `pwsh tools/test.ps1` в Windows или `sh tools/test.sh` в
  Linux. Что для этого нужно — в [CONTRIBUTING.md](../../../CONTRIBUTING.md).
- `lume-lab` собирается вместе с тестами и на настоящем ядре проходит по
  аккаунтам, восстановлению, постквантовому рукопожатию, атакам и номерам
  безопасности, отмечая каждую проверку `[ ok ]` или `[FAIL]`.
- Спецификация описывает, что должен делать код. Если код с ней не совпадает,
  ошибка в одном из двух.

## Как участвовать

Изменения принимаются через pull request с подписью (sign-off) по
лицензионному соглашению участника из
[CONTRIBUTING.md](../../../CONTRIBUTING.md). Об уязвимостях сообщайте
конфиденциально — см. [Уязвимости](/security/).

## Этот сайт

Сайт собирается из того же репозитория: в [`site/`](../../../site) лежит
небольшой генератор на стандартной библиотеке Python, а документы выводятся
прямо из [`legal/`](../../../legal), поэтому сайт и репозиторий не могут
разойтись. На сайте один небольшой скрипт — для окна cookie и заголовка на
главной; cookie ставятся только с вашего согласия, и ничего не загружается с
других серверов. Подробнее — [Сайт и cookie](/legal/website/).
