**All documents are drafts** until the first public release. Before that
release they need: the contact addresses, the hosting provider and server
location, and a review by a lawyer admitted in Kazakhstan. Each fact that is not
settled yet is an *Important* note starting with **To be filled in before
release** (**Заполнить до выпуска** in Russian, **Шығарылымға дейін толтыру
керек** in Kazakh); `python site/build.py` lists how many each document has
left. The Kazakh texts are translations that a native-speaking lawyer has not
reviewed yet.

The website renders these files as they are, from `site/`; nothing is copied.

These policies describe what the software does. If the code and a policy
disagree, that is a defect to fix before release, never a policy to leave as
written.
