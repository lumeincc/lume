# Сведения для магазинов приложений

Ответы LUME в формах о данных и содержании каждого магазина. Они выведены из
[Политики конфиденциальности](PRIVACY.ru.md) и описания
[разрешений](PERMISSIONS.ru.md); если меняется что-то из них, эта страница
меняется в том же коммите.
English version: [STORE-DISCLOSURES.md](STORE-DISCLOSURES.md).

## Google Play — Безопасность данных

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт данные пользователей? | Да — собирает один тип данных, никому не передаёт |
| **Личные данные → Идентификаторы пользователя** | **Собираются**: имя пользователя. Не передаются. Обязательны. Цели: работа приложения, управление аккаунтом. Обрабатываются не только временно |
| Сообщения, фото, видео, файлы | Передаются только со сквозным шифрованием, ТОО «LUME Inc.» их прочитать не может. По правилам Play данные со сквозным шифрованием не считаются собираемыми — перед отправкой формы сверьтесь с актуальной справкой Play Console |
| IP-адрес | Обрабатывается временно, в оперативной памяти, для доставки и защиты от злоупотреблений; не хранится |
| Местоположение, контакты, финансовые данные, здоровье, действия в приложении, история браузера, идентификаторы устройства, диагностика | Не собираются |
| Передача третьим лицам | Нет |
| Шифрование при передаче | Да |
| Пользователь может запросить удаление | Да — *Удалить аккаунт* в приложении сразу удаляет все данные на сервере; веб-страница, которую требуют магазины, — [ACCOUNT-DELETION.ru.md](ACCOUNT-DELETION.ru.md) |
| Независимая проверка безопасности | Пока нет — обновим, когда будет проведена |

Другие декларации Play:

- **Целевая аудитория:** 16+, не предназначено для детей.
- **Возрастной рейтинг:** пользователи могут общаться и обмениваться
  содержимым.
- **Стандарты защиты детей:** опубликованы в [CHILD-SAFETY.ru.md](CHILD-SAFETY.ru.md),
  есть жалоба в приложении и ответственный контакт.
- **Foreground service:** тип `remoteMessaging`, только если пользователь
  включил *Фоновое подключение*.
- **Реклама:** отсутствует.

## RuStore

- Категория: Общение. Возрастной рейтинг: 16+.
- Политика конфиденциальности: [PRIVACY.ru.md](PRIVACY.ru.md).
- Нет платежей, рекламы и сторонних SDK.

## Microsoft Store

- Политика конфиденциальности: [PRIVACY.md](PRIVACY.md) (обязательна для
  приложений, работающих с сетью).
- Возможности: только `internetClient`.
- Возрастной рейтинг через анкету IARC: пользователи взаимодействуют, покупок
  нет.

> [!IMPORTANT]
> **Заполнить до выпуска:** адреса на сайте для политики конфиденциальности и
> страницы удаления аккаунта, которые требует каждый магазин.

## Не применимо

- **Политика возврата средств:** покупок нет — раздел 6
  [Пользовательского соглашения](TERMS.ru.md).
- **Корпоративное управление устройствами (MDM / MAM):** LUME не предлагает
  управляемую конфигурацию и политики защиты приложений — это мессенджер для
  частных лиц.
